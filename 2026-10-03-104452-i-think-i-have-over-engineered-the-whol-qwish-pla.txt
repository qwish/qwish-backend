⏺ Here are the ERP features, meaning school-administration features rather than
  the quiz and learning product. All of them come from the route dump and folder
  scan above.

  1. Admissions & enrollment

  - Admission policy plus a policy tester. institution: /admissions/policy,
    /admissions/policy/test
  - Admission request queue with counts and approve/reject. /admissions/requests
  - Transfer flow between institutes, where the student has to confirm.
    students/join/requests/{id}
  - Join by code: preview → confirm. /students/join/preview|confirm
  - Claim codes for pre-created students. /students/claim
  - Enrollment records, status changes and bulk status.
    /enrollments/{id}/status, /enrollments/bulk-status
  - Promotions between academic years: promote, batches, revert.
    /enrollments/promote, /promotions, /promotions/{batchId}/revert
  - Roster creation: manual add plus CSV import. /students, /students/import
  - Student find/explain/ids lookup. /students/find, /students/explain,
    /students/ids
  - Student status (active/suspended). /students/{id}/status

  2. Academic structure

  - Academic years and departments. Dashboard academics/
  - Curriculum versioning: a grade → subject → chapter → concept tree, immutable
    published versions, assigned to class/year. Domains curriculum, learning
  - Mapping questions to curriculum units, plus learning maps.
    /teacher/questions/{id}/learning-map
  - Students read the class curriculum. /users/me/curricula, numpie curriculum/
  - Groups/classes CRUD, adding students/teachers to groups. /groups/*

  3. Staff management (HR-like)

  - Teacher invites, resend and invite list. /teachers/invite,
    /teachers/invites/*
  - Teacher status, removal and counts. /teachers/{id}/status, /teachers/counts
  - Teacher activity report. /reports/teacher-activity
  - Leadership views. Domain leadership, teacher panel leadership/
  - Teacher feature onboarding and preferences. /teacher/feature-onboarding

  4. Workflow queues & approvals

  - Enrollment edit requests (identity corrections), teacher → institute. Domain
    editrequest
  - Topic requests, student → teacher → institute. Domain topicrequest
  - Action centre with owner assignment. /action-centre, /action-centre/owner
  - Setup checklist. /setup-checklist
  - Referral code reset requests. /referral-code-reset-request
  - Portfolio entry review: submit → reviews.
    /users/me/profile-entries/{id}/submit|reviews

  5. Pedagogy case management

  - Assignments with purpose types (baseline/practice/follow_up/diagnostic),
    recipients, reminders and close
  - Follow-up outcomes review. /teacher/follow-up-outcomes
  - Misconception tracking and review per student. /teacher/misconceptions
  - Student support notes. /teacher/students/{id}/support, /support-reviews
  - Learning evidence per student. /students/{id}/learning-evidence
  - Class learning matrix. /teacher/class-learning-matrix

  6. Parent portal

  - Parent ↔ child linking: invite, accept, remove. /parent/*
  - Child overview for parents
  - Teacher-written parent summaries behind a public token link.
    /public/parent-summaries/{token}

  7. Reporting & BI

  - 5 institute reports: student performance, teacher activity, quiz analytics,
    streak health, points summary
  - Metrics catalog plus distributions, duplicated ×3 (teacher/institute/admin).
    Domain metrics
  - Custom dashboard layouts with CRUD and reorder, also ×3. /dashboard-layouts
  - Learning summary, scoped and unscoped
  - Weekly digests and insights emails (cron)

  8. Governance, compliance & security

  - Audit log in both institute and super-admin
  - Admin accounts CRUD, resend and passkey reset. /admin/admin-accounts
  - Security policy. /admin/security-policy
  - Session management and revoke-others, in both admin and user
  - Impersonation start/end
  - Student merge, purge and duplicate detection
  - Notification log

  9. Finance-like

  - Point economy config. /point-economy
  - Points reserve and points liability, the latter ×3
  - Per-institute point rules and multipliers
  - Points expiry (cron)

  10. Platform tenancy

  - Institute application → review queue → approve/reject/suspend/reactivate
  - Provisioning the institute admin and resending credentials
  - Brand accounts plus sponsorship request approval
  - Announcements with audience estimate, promos and surveys
